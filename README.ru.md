# Русские субтитры для VLC через Codex

Плагин переводит встроенные и внешние субтитры на русский через ваш аккаунт
Codex CLI. Основной источник может быть на любом языке. Другие синхронизированные
переводы можно добавить как справочные источники.

[English](README.md) · [Скачать](https://github.com/mavaurel/vlc-codex-subs/releases/latest) · [История версий](CHANGELOG.md)

Тайминги и защищённое форматирование сохраняются. Если после перепроверок фраза
остаётся неясной, плагин оставляет оригинал и отмечает её в отчёте. Для неясных
PGS/DVD сохраняются исходные изображения букв. OCR и автоматическая проверка
снижают число ошибок, но не гарантируют безошибочный перевод.

## Установка

Нужны **VLC 3**, **Python 3.10+**, **Codex CLI** с выполненным входом и
**FFmpeg/FFprobe** для встроенных дорожек. Python-пакеты для работы не требуются.

1. Установите [VLC](https://www.videolan.org/vlc/), Python и FFmpeg. На Mac с
   [Homebrew](https://brew.sh/):

   ```sh
   brew install python ffmpeg
   brew install --cask vlc
   ```

2. Установите [Codex CLI по официальной инструкции](https://github.com/openai/codex#installing-and-running-codex-cli).
   Если Node.js/npm уже установлен:

   ```sh
   npm install -g @openai/codex
   codex login
   ```

3. Скачайте `vlc-codex-subs-1.6.2.zip` из
   [последнего релиза](https://github.com/mavaurel/vlc-codex-subs/releases/latest),
   распакуйте и запустите в терминале:

   ```sh
   cd /путь/к/vlc-codex-subs-1.6.2
   python3 install.py
   ```

   На macOS файл `Install.command` запускает тот же установщик. Если Finder
   блокирует скачанный скрипт, используйте команду в терминале выше.
   Для нестандартного расположения Codex: `python3 install.py --codex /полный/путь/codex`.

4. Перезапустите VLC. На macOS откройте **VLC media player → Extensions → Codex
   Russian Subtitles**; на Linux — меню **Вид / View**.

Установка выполняется в ваш пользовательский каталог. Установщик запоминает
полные пути к Python и Codex — не удаляйте их после установки. Если пути
изменились, запустите установщик снова.

Для **PGS OCR** дополнительно нужны macOS **13+** и инструменты Apple:

```sh
xcode-select --install
```

При первом запуске OCR локально собирается Swift-помощник. Распознавание и
измерение ширины строк выполняются на Mac. В ZIP нет готовых нативных бинарников.

## Как пользоваться

1. Откройте видео и плагин: дорожки определяются автоматически.
2. В **Subtitles to translate** выберите основной источник.
3. При желании добавьте другие переводы через **Add reference**. Они должны быть
   от того же фильма/эпизода, монтажа и иметь совпадающую временную шкалу.
   По умолчанию дополнительные источники не выбраны.
4. Нажмите **Create Russian subtitles**. Просмотр можно продолжать.
5. **Refresh progress** показывает актуальный этап и загружает готовый результат.

Готовый файл сохраняется рядом с видео, если папка доступна для записи, и
дополнительно в каталоге задания вместе с `review.json`. Исходники и существующие
файлы не перезаписываются. Плагин загружает перевод только в соответствующее
видео. При смене видео восстанавливается его собственное задание.

Закрытие VLC не отменяет работу. **Cancel translation** останавливает обработку;
результаты OCR, черновики и проверенные фрагменты сохраняются для подходящего
повторного запуска. Если помощник уже завершился, отмена сбрасывает зависший статус.

## Форматы и ограничения

- **macOS и Linux:** SRT, ASS/SSA, WebVTT и встроенные текстовые дорожки.
- **macOS 13+:** встроенные PGS и внешние `.sup`; результат в ASS.
- **macOS с дополнительной сборкой:** локальные незашифрованные DVD-папки `VIDEO_TS`.

Windows, отдельные VobSub, DVD-дорожки внутри обычного видеофайла, физические и
зашифрованные диски, а также вшитые в видеокартинку субтитры не поддерживаются
расширением. Шрифты, курсив и цвета растровых субтитров не восстанавливаются точно.
Длинные русские строки из OCR переносятся и подгоняются по ширине без удаления слов.
Стили исходных авторских ASS сохраняются; ASS с караоке и векторными рисунками
не принимается как вход для перевода.

## Скорость и проверка

Режим **Light**: `gpt-6.1-sol`, low reasoning, пакеты по 64 реплики и четыре
параллельных воркера. **Careful**: medium reasoning, один воркер, по 32 реплики.
В обоих режимах каждый пакет проходит перевод и отдельную проверку верности.
Если модель недоступна вашему аккаунту, выберите доступную в **Model settings**.

Неясные фразы проверяются повторно с соседними репликами и отдельным
подтверждением. Неразрешённые остаются в оригинале и попадают в `originals_kept`
в отчёте. Код не снимает отметку неуверенности модели ради завершения задания.

Для 15 воркеров и Fast измените соответствующие поля установленного `config.json`
перед новым заданием. Остальные поля конфигурации оставьте на месте:

```json
{
  "workers": 15,
  "chunk_size": 64,
  "service_tier": "fast",
  "keep_original": true,
  "save_beside_video": true
}
```

Допустимо 1–15 воркеров. По умолчанию Fast выключен. Доступность Fast и расход
лимитов зависят от Codex и вашего плана: [официальное описание](https://learn.chatgpt.com/docs/agent-configuration/speed).
Большее число воркеров может вызвать ограничения сервиса: плагин выдерживает
общую паузу и уменьшает параллелизм. Fast не обходит ограничения. Фиксированное
время перевода не гарантируется. `chunk_size: 0` включает автоматические крупные
запросы с разделением при неполном ответе или тайм-ауте.

## Данные и конфигурация

Выбранный текст субтитров и отмеченные для перепроверки фрагменты изображений
отправляются через ваш аккаунт Codex. Обычные изображения без замечаний остаются
локально. Используется существующий вход в Codex и лимиты вашего аккаунта.
Плагин не устанавливает сервер и не открывает сетевой порт.

На macOS задания и настройки находятся здесь:

```text
~/Library/Application Support/VLC Codex Subtitles/
  config.json
  cache/
  jobs/<номер>/Russian.srt  (или .ass/.ssa/.vtt)
  jobs/<номер>/review.json
```

На Linux: `$XDG_DATA_HOME/vlc-codex-subtitles`, по умолчанию
`~/.local/share/vlc-codex-subtitles`. Путь Lua-расширения и все параметры CLI
описаны в [английской инструкции](README.md).

## Поддержка DVD-папок

Дополнительная сборка на Mac требует **Python 3.12+**, Apple Command Line Tools
и Homebrew-библиотеки:

```sh
brew install libdvdnav libdvdread pkg-config
python3 setup_dvd.py
python3 install.py
```

Скрипт скачивает исходники FFmpeg с проверкой SHA-256, применяет записанное
исправление DVD-таймингов и собирает отдельный помощник. Системный FFmpeg не
изменяется. Библиотеки libdvdnav/libdvdread должны оставаться установленными.
Лицензии зависимостей описаны в [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

Откройте нужный DVD-титул в VLC и заново откройте расширение. В списке указаны
титул, длительность, дорожка и язык. Если титул определить не удалось, явно
выбирается самый длинный. Разные титулы имеют отдельные задания и имена файлов.
Исходники внутри `VIDEO_TS` не изменяются.

## Обновление и удаление

Для обновления распакуйте новый релиз и запустите `python3 install.py`. Затем
заново откройте расширение или перезапустите VLC. Настройки и результаты
сохраняются. Уже запущенные воркеры продолжают работать со старой версией.

Удалить расширение, сохранив результаты и настройки:

```sh
python3 install.py --uninstall
```

Если прогресс не меняется, посмотрите `launcher.log` и `worker.log` в каталоге
задания. При ошибке входа выполните `codex login`. Если готовый перевод не виден,
нажмите **Refresh progress** или загрузите файл через меню субтитров VLC.
